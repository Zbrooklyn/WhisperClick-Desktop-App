# PART 1 — DICTATION TOOLS

## 1. Wispr Flow — https://wisprflow.ai
AI dictation into any app with auto-editing + AI cleanup. Mac, Windows, iOS, Android (waitlist); cross-device sync.

**Pricing**
- **Free (Basic)** — weekly word caps (reset Sun): desktop 2,000 words/wk (5,000 hard cap), iOS 1,000/wk (1,500 cap), Android unlimited (promo). Core dictation, personal dictionary, 100+ languages, Privacy Mode, HIPAA-ready.
- **Pro** — $15/mo · $12/mo annual ($144/yr). Unlimited words all platforms + Command Mode (voice editing), priority support, early access. 14-day trial, no card.
- **Team** — ~$12/mo · ~$10/mo annual, 3-seat min (⚠️ unconfirmed on live page). + team mgmt, central billing, shared dictionary/snippets.
- **Enterprise** — custom, annual. + SOC 2 Type II, ISO 27001, enforced HIPAA/Privacy, SSO/SAML, usage dashboards, IT admin seats.
- Students 3mo free +50% off; nonprofit/edu discounts. No lifetime.

**Features:** dictate into any app · 100+ languages · Whisper mode (works when whispering) · backtracking (self-corrections) · filler-word removal · auto punctuation · voice list formatting · context-aware name spelling · personal dictionary · snippets/voice shortcuts · tone styles (formality by app; English/desktop) · Command Mode (Pro, voice-edit existing text) · shared dictionary/snippets (team) · usage dashboards + Team Leaderboard · developer features (filename tagging in Cursor/Windsurf, camelCase/snake_case syntax awareness, dev terminology) · Privacy Mode / HIPAA / SOC2 / SSO.

**Sentiment:** G2 4.5/5 vs. Trustpilot only 2.7/5 — the sharpest curated-vs-organic gap in the set. Dominant complaint: reliability degrades noticeably after the free trial ends / after payment starts (one description: "working 60% of the time" post-payment), plus resource usage on older machines, Windows freezes, privacy concerns about the screen-capture context feature. Reddit routes privacy/power users to superwhisper instead. Independent real-world accuracy estimate: ~97.2% on standard English, comparable to other cloud STT — not the outlier the marketing implies.

## 2. superwhisper — https://superwhisper.com
Hold-a-hotkey dictation + AI cleanup, strong offline/local story. Mac, Windows, iOS.

**Pricing**
- **Free** — $0. Voice-to-text in any app, meeting recording + transcription, 100+ languages, **unlimited small LOCAL models** (on-device), custom prompts.
- **Pro** — $8.49/mo · $84.99/yr (~$7.08/mo). + BYO API key, unlimited cloud + large local models, translation to English, audio/video file transcription, priority support.
- **Lifetime** — **$249.99** (RESOLVED — the $849 figure was a stale/wrong scrape or different SKU; official current price is $249.99, one-time, all future updates + all paid features across macOS/Win/iOS).
- **Enterprise** — custom. SOC 2 Type II, centralized billing, model controls, enterprise-hosted models.
- 30-day refund, 40% student discount.

**Features:** any app/site · hotkey (⌥+Space) + push-to-talk · auto-paste · offline/local transcription · small (free) + large (Pro) local models + cloud models · multiple cleanup LLMs (GPT-5, Claude Haiku, Llama, Grok, Gemini, Ministral) · BYO API key · predefined Modes (Voice/Message/Email) + tone presets (Formal/Casual/Legal/Chat) · Custom Mode · **Super Mode (screen-aware)** · custom prompts/transformations · custom vocabulary · 100+ languages · translation (Pro) · meeting + file transcription · agentic coding integration (Cursor, Claude Code).

**Sentiment:** No aggregate star rating found, but consistently rated highest on accuracy/features among the dictation tools; proper-noun handling is its weak point, and free-tier accuracy is weaker (tiny/base local models only). Top complaint (community-upvoted): audio recordings saved by default with no built-in opt-out. Second: setup complexity ("like configuring a server"). Reddit favors it for privacy-minded + cost-minded users.

# PART 8 — TRANSCRIPTION ACCURACY: THE HONEST STATE

**Almost no independently-verified, product-level word-error-rate (WER) data exists for these apps.** What IS benchmarked is the underlying STT *engines*, not the finished products — a distinction the vendor marketing collapses.

**Engine-level data (2026):**
- OpenAI Whisper Large-v3 (what WhisperClick + several competitors route through): 2.7% WER on LibriSpeech test-clean (best case), 5.2% test-other, **8–12% on real-world English** — the range that actually matters.
- Cross-engine: Deepgram Nova-3, GPT-4o-Transcribe, AssemblyAI Universal-2 cluster sub-7% WER on real-world audio; AssemblyAI Universal-2 / Speechmatics Ursa 3 lead on noisy (~7.9–8.0%); AssemblyAI Universal-3 Pro (Feb 2026) claims 5.6% mean WER; Google Cloud Chirp trails at 11.6%.
- Reality caveat: a provider showing 5% WER on a clean benchmark can deliver 15–20% on real production audio (accents, cross-talk, jargon, bad mics).

**Per-product accuracy claims — all self-reported except one:**
- Aqua Voice — 3.2% WER on LibriSpeech clean (the only competitor with a real-looking number; still self-reported, still the easy benchmark).
- Willow Voice — no independent benchmark exists; "3x more accurate than native" is vendor-only.
- Dragon — informal, dated "85–90% on technical terms"; "up to 99%" is vendor-only.
- Otter, Fireflies, Fathom, tl;dv, Read.ai — **none publish a WER number at all.** Their accuracy reputations are pure user perception, not measured data.

**Bottom line:** every accuracy claim in this document — Aqua's 97.3%, Dragon's 99%, Willow's "3x," Wispr's figures — is an unverified vendor claim. There is also **no independent benchmark for WhisperClick's own accuracy** yet, so there's nothing to benchmark it against even if we wanted to — a real gap on our side, not just the competitors'.

# PART 9 — WHERE WHISPERCLICK SITS

**Core dictation (vs Wispr, superwhisper, Aqua, Willow, MacWhisper, Dragon):**
- **Price:** $4.99/mo undercuts the entire subscription field (others $8–15/mo entry). Only MacWhisper's €64 one-time is structurally cheaper long-run (Mac-only, no mobile, no cloud modes).
- **Free tier:** OSS + fully local + unlimited — more generous than word-capped free tiers (Wispr 2K/wk, Aqua 1K-total, Willow limited model). Closest free peer: superwhisper.
- **Parity:** matches or beats the paid feature sets on punctuation, vocabulary, snippets, tone, live streaming, post-processing.
- **Gaps:** no voice-edit-existing-text mode (Wispr Command / Dragon select-say / Willow Scribe have it); screen-awareness is narrower than superwhisper/Aqua.

**Meeting (vs the full notetaker + bundled set):**
- **Genuine differentiators:** live (not post-meeting) action items + live chapters + live speaker labels + auto-detect-end + pause/resume — most of the field only produces these after the call ends. Mobile-first meeting mode when the whole field is weaker on mobile than their desktop marketing implies.
- **The one structural gap:** mic-only capture — cannot yet hear other call participants. Every one of the 14 meeting competitors can (bot-join / system-audio / native-platform). **This is the #1 priority fix (system-audio capture), and it undercuts everything else until closed.**
- **Also missing:** calendar auto-title/attendees (credential-gated), CRM sync, team/enterprise admin (SSO/SOC2/HIPAA), sentiment/coaching analytics (not our category), hardware.

**Unmatched WhisperClick strengths worth defending:** the Actions/macro library and Re-transcribe (diff + version history) categories have essentially no equivalent across all 25 competitors.
