WhisperClick · History header

Current vs. refined

Same layout, same one-tap actions, no menus anywhere. Just the two things that were actually wrong: the buttons get labels (clear) and their own row off the search line (uncrowded).

Now
Five unlabeled icons crammed against the search box: cramped, and a guessing game.
Refined
Labeled action cells on their own row; search gets room. One tap each, still zero menus.

What changed, and what didn't

Unclear → clear
Each action gets a one-word label under its icon. No more decoding five look-alike glyphs.
Cramped → roomy
The actions move to their own row, so the History line is just the title, count, and a search box with space to breathe.
No menus
Every action is still one direct tap. Files opens the file picker, URL opens a URL field, Live starts a meeting. Nothing opens a menu, so there's never a menu-in-a-menu.
Scales
A new paid capture source is just one more labeled cell in the row, and it never re-crowds the header or spawns a submenu.
