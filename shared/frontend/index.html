Why hotkeys conflict

Some key combos are already claimed by your OS, browser, or code editor. When that happens, the other app wins and WhisperClick never sees the keypress.

  • Ctrl+Shift+WCloses terminal windows and browser tabs
  • Ctrl+Shift+KDeletes lines in VS Code
  • Alt+FOpens File menu in most apps

WhisperClick can't override shortcuts claimed by your OS, browser, or editor.

Understanding the warnings

Blocked — Hard conflicts, can't be set (Ctrl+C, Alt+F4, etc.)
Warning — Likely conflicts, allowed but flagged (Ctrl+Shift+Letter, Alt+Letter)
Safe — No known conflicts (Ctrl+Alt combos, F-key combos)
